# 編集方針メモ（style notes）

編集者（オーナー）からのフィードバックで、今後の号でも守る方針をここに追記していく。
毎日の号を書く前に必ず読む（`.claude/skills/daily-issue/SKILL.md` の手順 3）。

## 現在の方針

- 文体は常体（だ・である調）。レビュー期間中に変更の可能性あり。
- 新しい構造を報告した論文はすべて記事にする（1 日 15 本を超える日だけ、残りを一覧に回す）。
- 対象は査読済みのオープンアクセス論文のみ（bioRxiv は後で追加）。
