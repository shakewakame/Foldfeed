## 2026-10-15（Europe PMC が止まったときの代替：PMC のオープンデータ）

| 項目 | 決定 |
|---|---|
| なぜ PubMed でないか | NCBI のサーバー（PubMed・E-utilities・PMC・FTP）は開発環境から接続できない（403）。PubMed は要旨しか持たず、記事に要る全文・PDB ID・ライセンスは PMC の全文が必要 |
| 代替 | NLM 公式の **PMC オープンアクセスデータ（AWS Open Data：`pmc-oa-opendata.s3.amazonaws.com`）**。接続できる。論文ごとにメタデータ（JSON：題名・DOI・PMID・ライセンス）と全文（JATS XML・テキスト）がある。Europe PMC が止まっていた間も新着が入り続けていた（10/10 以降で 8,554 本以上） |
| 切り替え | **自動**。Europe PMC の健康診断が「停止」のときだけ使う（普段は Europe PMC：全文検索を向こうでやってくれて軽い）。両方とも新着がなければ、号を作らず終了コード 3 |
| 絞り込み | 検索機能がないので、期間に書き込まれた記事の本文テキスト（1 本 約 60 KB、約 20 本/秒）を読み、Europe PMC の検索と同じ語（構造の語×寄託の語、注目の構造の語）で絞る。合致した記事の XML だけを読む。出版が 21 日より古い記録（メタデータの書き換えだけ）、撤回・著者原稿・プレプリントは除く |
| 出典の表示 | NLM の利用条件（出典を明記する、再配布が許されたデータだけを配布する）に従い、**この経路で作った号のページのフッター（と、その号が最新のときのホームのフッター）にだけ**「この号の論文情報と全文は、NLM の PMC オープンアクセスデータセット（AWS Open Data）から取得した」を出す。Europe PMC の号には出さない（オーナーの指示 2026-10-15）。号の README にも書く |
| 検証 | Europe PMC が動いていた期間の記事で確かめた：既存の全号の「新しい構造」26 本は、**26 本すべてが PMC の AWS に存在し、本文テキストの絞り込みを通った**（取りこぼし 0）。10/09〜10/10 の窓では、Europe PMC の候補 83 本のうち 55 本、残りの 28 本はすべて新しい構造のない論文（`no_ids`）。窓の端で日付がずれる（S3 の書き込み日と Europe PMC の索引日が 1 日違うことがある）ため、窓は連続して取る（`--catch-up`）。直近 4 日分（10/11〜10/14）では 9,570 本のうち 137 本が合致し、新しい構造 24 本＋ID が補足資料のみ 3 本の候補になった（過去の号の 1 日 3〜7 本と同じ規模） |
| 追いかけ | この経路の号は「その期間を扱った」ものとして数える（`--catch-up` の起点）。Europe PMC が回復しても、すでに出た論文は重複しない |

## 前提とする方針（提案時に合意したもの）

- 毎日のニュースレターを入口にし、タンパク質起点の情報基盤を最終形にする。
- 論文は初日から UniProt ID・PDB ID に紐づけた構造化データとして蓄積する。
- 数値・ID・リガンドは AI ではなくデータベース（PDB / UniProt）から取得する。
- AI の主張には本文からの根拠引用を付け、機械的に照合する。
- 構造図は画像生成 AI を使わず、PDB の座標から描く（2026-10-10 にグラフィカルアブストラクトをやめ、タンパクの図だけにした）。
- 論文の図を転載するのは CC BY の論文に限る。ライセンスは論文ごとに自動判定する。
