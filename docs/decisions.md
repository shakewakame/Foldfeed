## 2026-10-15（Europe PMC が止まったときの代替：PMC のオープンデータ）

| 出典の表示 | NLM の利用条件（出典を明記する、再配布が許されたデータだけを配布する）に従い、**この経路で作った号のページのフッター（と、その号が最新のときのホームのフッター）にだけ**「この号の論文情報と全文は、NLM の PMC オープンアクセスデータセット（AWS Open Data）から取得した」を出す。Europe PMC の号には出さない（オーナーの指示 2026-10-15）。号の README にも書く |

## 前提とする方針（提案時に合意したもの）

- 毎日のニュースレターを入口にし、タンパク質起点の情報基盤を最終形にする。
- 論文は初日から UniProt ID・PDB ID に紐づけた構造化データとして蓄積する。
- 数値・ID・リガンドは AI ではなくデータベース（PDB / UniProt）から取得する。
- AI の主張には本文からの根拠引用を付け、機械的に照合する。
- 構造図は画像生成 AI を使わず、PDB の座標から描く（2026-10-10 にグラフィカルアブストラクトをやめ、タンパクの図だけにした）。
- 論文の図を転載するのは CC BY の論文に限る。ライセンスは論文ごとに自動判定する。
